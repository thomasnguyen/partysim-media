# PartySim media

Animated loops for the PartySim project page (Kiroween 2026). AVIF, 60 fps, 10-bit colour.

- `loops/r1-night-falls.avif`: one tap on the sun and the house turns to night while guests walk in
- `loops/r2-the-fix.avif`: the drinks line, one tap on a second drinks table, the same night replayed
- `loops/r1-night-falls-compare.webp`: the same loop as WebP, for comparison
