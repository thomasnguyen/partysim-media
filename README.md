# PartySim media

Animated loops for the PartySim project page (Kiroween 2026). AVIF, 30 fps, 10-bit colour (Safari plays 60 fps animated AVIF at about half speed).

- `loops/h0-hero.avif` (and `-880` for the README): night falls, the drinks-line fix, a guest's RSVP walks up the path
- `loops/r2-the-fix.avif`: the drinks line, one tap on a second drinks table, the same night replayed
- `loops/r3-door.avif`: a guest's phone: their name on the front door, a tap, the trailer
- `loops/r5-scare.avif`: a scare cue in the living room
- `loops/r6-guest-card.avif`: tap a guest and read their night
- `loops/r7-shop-glow.avif`: point at a line on the shopping list and its pumpkins glow
- `loops/s0-setup-v2.avif`: a floor plan becomes a house, then our house gets its photos, a look and night
- `loops/s0-setup.avif`: an earlier cut of the same
- `loops/a14-wedding.avif`: next: an invented garden venue for a wedding
- `loops/r1-night-falls*.avif`, `r1-night-falls-compare.webp`: the 14 Nov format tests
- `loops/crew.png`: the Kiro crew, from request to pull request
- `loops/crew-loop.avif`: the crew at work, from a request to main
- `loops/crew-pictures.jpg`: the crew runs on pictures (pull request #6)
- `loops/crew-timeline.jpg`: every pull request the crew opened, 10 to 13 November
